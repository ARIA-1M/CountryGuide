#  Гид по странам (Country Guide)

Веб-приложение для автоматизации финансового и информационного сопровождения путешественников. Пользователь выбирает страну и получает актуальные статьи, полезные локальные приложения, разговорник с базовыми фразами на местном языке и расчитывает свои затраты в поездке.

##  О проекте

Гид по странам — это проект, разработанный в рамках учебной практики. Приложение помогает путешественникам:

- Читать актуальные статьи о стране
- Находить полезные локальные приложения (карты, такси, переводчики)
- Изучать базовые фразы на местном языке с транслитерацией
- Рассчитать бюджет на поездку

### Основной функционал

| Модуль | Описание |
|--------|----------|
| **Страны** | Просмотр списка стран с информацией о валюте, налоге и языке |
| **Статьи** | Просмотр статей о выбранной стране (название — ссылка на источник, дата обновления) |
| **Приложения** | Просмотр локальных приложений с описанием и логотипом |
| **Разговорник** | Просмотр категорий фраз и самих фраз (оригинал, перевод, транслитерация) |
| **Бюджет** | Создание поездки и расчёт всех затрат на неё по дням с возможностью пороговых уведомлений |
| **Администрирование** | CRUD-операции для статей, приложений, категорий и фраз (доступно только администраторам) |

## Технологии

| Компонент | Технология |
|-----------|------------|
| Backend | Python 3.13+, Django 6.0.5 |
| База данных | SQLite (разработка) |
| Frontend | HTML, CSS (адаптивный дизайн), JavaScript |
| Версионирование | Git, GitHub |

##  Установка и запуск
git clone https://github.com/ARIA-1M/CountryGuide.git
cd country-guide/GC/guide_project

python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

python manage.py migrate
python manage.py runserver
